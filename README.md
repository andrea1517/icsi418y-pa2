# ICSI418Y - Programming Assignment 2: Full-Stack Login and Signup

This basic login and signup application was built using MongoDB, Express, React, and Node.js.

Users are required to enter their first name, last name, username, and password when signing up for an account. Likewise, username and password are required to log into your account.

## Incomplete Features
- Does not support third-party logins or signups.
- No authenticators.
- No password hashing for now.
- No home page after logging in.
- Not aesthetically pleasing (_yet_).
